# 41 — Glossary
**Purpose:** Define project terminology  
**Audience:** All Developers / AI Agents  
**Last Generated:** 2026-08-31  
**Source of Truth:** Codebase terminology
---
| Term | Definition |
|------|-----------|
| **ByteVerse** | The coding competition and its platform |
| **NSDC** | Organizing body/committee |
| **VCET** | Host institution (Vidyavardhini's College of Engineering) |
| **Team** | A duo of exactly 2 participants |
| **Leader** | Team creator, gets Set A problems, isLeader=true |
| **Member** | Team joiner, gets Set B problems, isLeader=false |
| **Invite Code** | Auto-generated unique code for joining a team |
| **Round** | A timed competition phase (5 types) |
| **Round Type** | CODE_LOGIC, AI_REPAIR, TRADITIONAL, TYPE_TRANSFORM, HUMAN_VS_MACHINE |
| **Problem** | A question/challenge within a round |
| **Set A / Set B** | Problem subsets assigned to leader vs member |
| **Submission** | A participant's answer (MCQ selection or source code) |
| **Judge0** | External code execution engine |
| **Navigator** | AI EXPLAIN persona (Socratic tutor) |
| **Forge** | AI CODE persona (syntax advisor) |
| **AI Score Cap** | Maximum score allowed after AI usage (default 100, reduced by penalties) |
| **Proctor** | On-site invigilator who unlocks workstations |
| **Proctor PIN** | Master password to unlock anti-cheat locks (123456, 2026) |
| **Violation** | Anti-cheat event (tab switch, blur, fullscreen exit) |
| **Workstation Lock** | Anti-cheat modal requiring PIN to dismiss |
| **Lifetime Limit** | Tournament-wide AI usage cap (15 EXPLAIN, 25 CODE) |
| **Idempotency Key** | UUID preventing duplicate submissions |
| **System Readiness Gate** | Pre-round checklist component |
| **Arena** | Active competition workspace |
| **Break** | 5-minute rest period between rounds |
